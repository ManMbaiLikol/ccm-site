# Conseil Camerounais de la Musique — site web

Site vitrine du Conseil Camerounais de la Musique (CCM), association à but non lucratif fondée à Douala en 2009.

Site statique (HTML, CSS, JavaScript sans dépendance), publié avec GitHub Pages.

## Contenu

- `index.html` : la page d'accueil (institution, Chantiers musicaux du Cameroun, observatoire, recommandations, publications, gouvernance, adhésion, partenaires)
- `assets/` : logo, photos des Chantiers musicaux 2024, couvertures et logos des partenaires
- `docs/` : *Introduction au schéma de développement de l'industrie musicale camerounaise* (FR et EN, PDF)

## Modifier le site

Éditer `index.html`, puis pousser sur la branche `main` : GitHub Pages republie le site en une à deux minutes.

Les données de l'observatoire, des étapes des Chantiers et du simulateur se trouvent en tête du premier bloc `<script>` (`CCM_THEMES`, `CCM_ETAPES`, `CCM_SCENARIOS`).
